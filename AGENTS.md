## Public web research

When you decide to search the public web or read a public webpage, first load `~/.pi/agent/skills/tavily-web/SKILL.md` and follow it as the **required interface**, including its fallback rules. The user need not mention the skill.

Do not load it preemptively or perform web research merely because a topic is mentioned. This rule does not apply to local inspection or authenticated service API operations. Keep all web-workflow specifics in the skill.
